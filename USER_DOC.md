# User documentation

- To start the stack: run `make` at repository root (Makefile should call docker-compose up --build).
- Access site at `https://mohamed.42.fr` (map domain to your local IP in `/etc/hosts`).
- Admin panel: WordPress admin at `https://mohamed.42.fr/wp-admin`.
- Credentials and secrets are stored in `./secrets` and should be managed locally.
